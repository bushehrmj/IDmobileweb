# ID Mobile Manager Pro

## سیستم مدیریت حرفه‌ای فروشگاه موبایل

یک سیستم کامل و واقعی برای مدیریت فروشگاه موبایل با قابلیت‌های پیشرفته، طراحی شده برای اجرا در شبکه محلی (Wi-Fi) مغازه.

---

## ویژگی‌های اصلی

### 🔐 امنیت و احراز هویت
- سیستم Login با رمز عبور Hash شده
- Session Management با زمان انقضا
- قفل شدن حساب پس از ۵ تلاش ناموفق
- تغییر رمز اجباری برای admin اولیه
- Audit Log برای تمام عملیات مهم

### 👥 مدیریت کاربران و دسترسی‌ها
- ۵ نقش کاربری: مدیر کل، مدیر فروشگاه، فروشنده، تعمیرکار، انباردار
- سیستم Permission دقیق (View, Create, Edit, Delete, Print, Export)
- منوی پویا بر اساس دسترسی کاربر
- کنترل دسترسی صفحه‌ای (403 برای دسترسی غیرمجاز)
- مدیریت Sessionهای فعال

### 💰 ماژول فروش
- ثبت فروش با بارکدخوان USB
- جستجو با IMEI
- مدیریت چند کالا در یک فاکتور
- تخفیف مبلغی و درصدی
- پرداخت نقدی، کارتخوان، ترکیبی، نسیه
- چاپ فاکتور حرفه‌ای (80mm, A5, A4)
- لغو و مرجوعی فاکتور
- محاسبه خودکار سود

### 📦 مدیریت محصولات
- ثبت کالا با بارکد و IMEI
- مدیریت موجودی
- هشدار موجودی کم
- تاریخچه تغییر قیمت
- قیمت پیشنهادی فروش بر اساس درصد سود

### 🏪 انبار
- ثبت ورود و خروج کالا
- اصلاح موجودی
- تاریخچه کامل حرکات
- مرجع هر حرکت (خرید، فروش، تعمیر)

### 🛒 خرید
- ثبت خرید از تأمین‌کننده
- ذخیره نرخ دلار در زمان خرید
- ثبت IMEI برای کالاهای وارد شده
- محاسبه بدهی به تأمین‌کننده

### 👤 مشتریان
- اطلاعات کامل مشتری
- محاسبه خودکار بدهی
- تاریخچه خرید
- Ledger حساب مشتری

### 🔧 تعمیرات
- پذیرش تعمیر با تمام جزئیات
- ۷ وضعیت تعمیر (دریافت، بررسی، تعمیر، منتظر قطعه، آماده، تحویل، لغو)
- ثبت قطعات مصرفی
- کسر خودکار از انبار
- محاسبه اجرت و هزینه
- مدیریت پرداخت و بدهی

### 📊 گزارش‌ها
- گزارش فروش (روزانه، هفتگی، ماهانه)
- گزارش سود
- گزارش خرید
- گزارش تعمیرات
- گزارش موجودی
- گزارش فروشندگان
- خروجی CSV

### 💳 پرداخت‌ها
- ثبت دریافت و پرداخت
- روش‌های مختلف پرداخت
- تاریخچه کامل

### ⚙️ تنظیمات
- اطلاعات فروشگاه (نام، تلفن، آدرس، لوگو)
- تنظیمات فاکتور
- تنظیمات چاپ
- تنظیمات امنیتی
- تم روشن/تاریک

- بازنشانی سیستم

## نصب و راه‌اندازی

### پیش‌نیازها
- Node.js 18+ (برای build)
- مرورگر مدرن (Chrome, Firefox, Safari, Edge)

### مراحل نصب

1. **Clone یا دانلود پروژه**
```bash
git clone <repository-url>
cd id-mobile-manager
```

2. **نصب وابستگی‌ها**
```bash
npm install
```

3. **Build پروژه**
```bash
npm run build
```

4. **اجرای سرور محلی**

#### روش ۱: استفاده از Python (ساده‌ترین)
```bash
cd dist
python -m http.server 3000
```

#### روش ۲: استفاده از Node.js
```bash
npm install -g serve
cd dist
serve -s . -l 3000
```

#### روش ۳: استفاده از PHP
```bash
cd dist
php -S localhost:3000
```

5. **دسترسی به برنامه**

روی کامپیوتر سرور:
```
http://localhost:3000
```

از موبایل/تبلت در شبکه محلی:
```
http://192.168.1.100:3000
```
(به جای `192.168.1.100` آدرس IP کامپیوتر سرور را وارد کنید)

### پیدا کردن IP کامپیوتر

**ویندوز:**
```cmd
ipconfig
```
به دنبال `IPv4 Address` بگردید.

**لینوکس/مک:**
```bash
ifconfig
# یا
ip addr show
```

## راهنمای استفاده

### ۱. اولین ورود
1. برنامه را باز کنید
2. با `admin` / `ChangeMe123!` وارد شوید
3. رمز جدید تعیین کنید

### ۲. ایجاد کاربران جدید
1. به منوی **کاربران** بروید
2. روی **کاربر جدید** کلیک کنید
3. نقش و دسترسی‌ها را تعیین کنید
4. کاربر را ذخیره کنید

### ۳. ثبت محصول
1. به منوی **محصولات** بروید
2. روی **کالای جدید** کلیک کنید
3. اطلاعات کالا را وارد کنید
4. اگر کالا IMEI دارد، تیک **نیاز به IMEI** را بزنید
5. ذخیره کنید

### ۴. ثبت IMEI
1. در صفحه محصولات، روی آیکون **بارکد** کنار کالا کلیک کنید
2. روی **+ افزودن IMEI** کلیک کنید
3. IMEI را وارد کنید

### ۵. فروش
1. به منوی **فروش** بروید
2. بارکد را اسکن کنید یا کالا را جستجو کنید
3. IMEI را وارد کنید (اگر لازم است)
4. مشتری را انتخاب کنید
5. تخفیف و پرداخت را تنظیم کنید
6. **ثبت و چاپ فاکتور** را بزنید

### ۶. پذیرش تعمیر
1. به منوی **تعمیرات** بروید
2. روی **پذیرش جدید** کلیک کنید
3. اطلاعات مشتری و دستگاه را وارد کنید
4. ایراد و عیب‌یابی را ثبت کنید
5. وضعیت را تعیین کنید
6. ذخیره کنید

### ۷. تغییر وضعیت تعمیر
1. تعمیر مورد نظر را ویرایش کنید
2. وضعیت را تغییر دهید
3. اگر **تحویل داده شد** را انتخاب کنید، قطعات مصرفی از انبار کسر می‌شود

### ۸. گزارش‌گیری
1. به منوی **گزارش‌ها** بروید
2. نوع گزارش را انتخاب کنید
3. بازه زمانی را تعیین کنید
4. برای خروجی CSV کلیک کنید

### ۹. پشتیبان‌گیری
1. به منوی **پشتیبان‌گیری** بروید
2. روی **ایجاد و دانلود پشتیبان** کلیک کنید
3. فایل JSON دانلود می‌شود
4. آن را در جای امن نگهداری کنید

### ۱۰. بازیابی پشتیبان
1. به منوی **پشتیبان‌گیری** بروید
2. روی **انتخاب فایل پشتیبان** کلیک کنید
3. فایل JSON را انتخاب کنید
4. تأیید کنید

## اتصال موبایل به شبکه محلی

### مرحله ۱: اتصال به Wi-Fi
مطمئن شوید کامپیوتر سرور و موبایل به یک شبکه Wi-Fi متصل هستند.

### مرحله ۲: پیدا کردن IP سرور
در کامپیوتر سرور، IP را پیدا کنید (مثلاً `192.168.1.100`)

### مرحله ۳: دسترسی از موبایل
در مرورگر موبایل وارد شوید:
```
http://192.168.1.100:3000
```

### مرحله ۴: Add to Home Screen (اختیاری)
در موبایل:
1. روی منوی مرورگر کلیک کنید
2. **Add to Home Screen** را انتخاب کنید
3. آیکون برنامه به صفحه اصلی اضافه می‌شود

## نکات مهم

### 🔒 امنیت
- رمز عبور admin اولیه را حتماً تغییر دهید
- از شبکه Wi-Fi امن استفاده کنید
-定期 از سیستم پشتیبان بگیرید
- کاربران غیرفعال را حذف کنید

### 💾 پشتیبان‌گیری
- روزانه پشتیبان بگیرید
- فایل پشتیبان را در چند مکان نگهداری کنید
- قبل از تغییرات مهم، پشتیبان بگیرید

### 🌐 شبکه
- برنامه کاملاً آفلاین کار می‌کند
- نیازی به اینترنت ندارد
- فقط Wi-Fi داخلی مغازه لازم است
- اگر اینترنت قطع شود، برنامه همچنان کار می‌کند

### 📱 موبایل
- برنامه کاملاً Responsive است
- در موبایل به‌خوبی کار می‌کند
- از بارکدخوان USB می‌توانید استفاده کنید
- Bottom Navigation برای دسترسی سریع

### 🖨️ چاپ
- فاکتور در ۳ سایز قابل چاپ است: 80mm, A5, A4
- از تنظیمات، سایز پیش‌فرض را تعیین کنید
- چاپ مستقیم از مرورگر انجام می‌شود

## سطوح دسترسی

### مدیر کل (Admin)
- دسترسی کامل به تمام بخش‌ها
- مدیریت کاربران
- تنظیمات سیستم
- پشتیبان‌گیری

### مدیر فروشگاه (Manager)
- دسترسی به تمام بخش‌ها به جز پشتیبان‌گیری
- مشاهده سود و گزارش‌های مالی

### فروشنده (Seller)
- فروش و فاکتور
- مشتریان
- محصولات (فقط مشاهده)
- داشبورد محدود

### تعمیرکار (Technician)
- تعمیرات
- مشتریان
- محصولات (فقط مشاهده)
- داشبورد تعمیرات

### انباردار (Warehouse)
- محصولات
- انبار
- خرید
- داشبورد موجودی

## عیب‌یابی

### برنامه باز نمی‌شود
- مطمئن شوید سرور در حال اجرا است
- IP و Port را بررسی کنید
- فایروال را بررسی کنید

### موبایل وصل نمی‌شود
- مطمئن شوید هر دو دستگاه به یک Wi-Fi متصل هستند
- IP سرور را بررسی کنید
- Port 3000 را باز کنید

### اطلاعات ذخیره نمی‌شود
- فضای localStorage مرورگر را بررسی کنید
- Cache مرورگر را پاک کنید
- از مرورگر دیگری استفاده کنید

### چاپ کار نمی‌کند
- Printer را در مرورگر انتخاب کنید
- تنظیمات چاپ را بررسی کنید
- از PDF استفاده کنید
