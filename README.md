## 🔧 عیب‌یابی

### مشکل ۱: برنامه اجرا نمی‌شود

**خطا:** `Cannot find module`

**راه‌حل:**
```bash
# پاک کردن node_modules و نصب مجدد
rm -rf node_modules package-lock.json
npm install
```

### مشکل ۲: پورت 3000 در حال استفاده است

**خطا:** `Error: listen EADDRINUSE: address already in use :::3000`

**راه‌حل ۱:** تغییر پورت
```bash
# ویندوز
set PORT=3001 && node server.js

# مک/لینوکس
PORT=3001 node server.js
```

**راه‌حل ۲:** بستن برنامه در حال استفاده
```bash
# ویندوز
netstat -ano | findstr :3000
taskkill /PID <PID> /F

# مک/لینوکس
lsof -ti:3000 | xargs kill -9
```

### مشکل ۳: موبایل وصل نمی‌شود

**بررسی‌ها:**
1. ✅ آیا هر دو دستگاه به یک Wi-Fi متصل هستند؟
2. ✅ آیا IP سرور صحیح است؟
3. ✅ آیا فایروال پورت 3000 را مسدود نکرده است؟

**باز کردن فایروال:**

**ویندوز:**
```
Control Panel > System and Security > Windows Defender Firewall
> Advanced Settings > Inbound Rules > New Rule
> Port > TCP > 3000 > Allow
```

**مک:**
```
System Preferences > Security & Privacy > Firewall
> Firewall Options > Allow incoming connections for Node.js
```

### مشکل ۴: اطلاعات ذخیره نمی‌شوند

**راه‌حل:**
1. Cache مرورگر را پاک کنید:
   - Chrome: `Ctrl + Shift + Delete`
   - Firefox: `Ctrl + Shift + Delete`
2. از مرورگر دیگری استفاده کنید
3. localStorage را بررسی کنید:
   ```javascript
   // در Console مرورگر
   console.log(Object.keys(localStorage));
   ```

### مشکل ۵: Build خطا می‌دهد

**راه‌حل:**
```bash
# پاک کردن cache
npm cache clean --force

# نصب مجدد
rm -rf node_modules package-lock.json
npm install

# Build مجدد
npm run build
```
