## 📖 راهنمای نصب و اجرا

### 🚀 شروع سریع (3 مرحله)

#### مرحله 1: نصب Node.js
اگر Node.js نصب نیست، از سایت رسمی دانلود کنید:
```
https://nodejs.org/
```
نسخه **LTS** را انتخاب کنید.

#### مرحله 2: نصب برنامه
روی فایل **`setup.bat`** دابل کلیک کنید و منتظر بمانید تا نصب کامل شود.

#### مرحله 3: اجرای برنامه
روی فایل **`start.bat`** دابل کلیک کنید. مرورگر به صورت خودکار باز می‌شود!

## 🌐 آدرس‌های دسترسی

### از کامپیوتر اصلی:
```
http://localhost:3000
```

### از موبایل/تبلت در شبکه محلی:
```

```
(به جای `192.168.1.X` آدرس IP کامپیوتر سرور را وارد کنید)

```cmd
ipconfig
```

به دنبال `IPv4 Address` بگردید.

## 💾 پشتیبان‌گیری

### ایجاد پشتیبان:
1. روی فایل **`backup.bat`** دابل کلیک کنید
2. فایل پشتیبان در پوشه `backup` ذخیره می‌شود
3. نام فایل شامل تاریخ و ساعت است

### بازیابی پشتیبان:
1. روی فایل **`restore.bat`** دابل کلیک کنید
2. نام فایل پشتیبان را وارد کنید
3. تأیید کنید
4. داده‌ها بازیابی می‌شوند

⚠️ **هشدار:** بازیابی پشتیبان، تمام داده‌های فعلی را پاک می‌کند!

## 🔧 عیب‌یابی

### مشکل: برنامه اجرا نمی‌شود
**راه‌حل:**
```cmd
# پاک کردن و نصب مجدد
rmdir /s /q node_modules
del package-lock.json
npm install
npm run build
```

### مشکل: پورت 3000 در حال استفاده است
**راه‌حل:**
```cmd
# پیدا کردن برنامه در حال استفاده
netstat -ano | findstr :3000

# بستن برنامه
taskkill /PID <PID> /F
```

### مشکل: موبایل وصل نمی‌شود
**بررسی‌ها:**
1. ✅ آیا هر دو دستگاه به یک Wi-Fi متصل هستند؟
2. ✅ آیا IP سرور صحیح است؟
3. ✅ آیا فایروال پورت 3000 را مسدود نکرده است؟

**باز کردن فایروال:**
```
Control Panel > System and Security > Windows Defender Firewall
> Advanced Settings > Inbound Rules > New Rule
> Port > TCP > 3000 > Allow
```

## 📱 اتصال موبایل

### مرحله 1: پیدا کردن IP سرور
```cmd
ipconfig
```
مثال: `192.168.1.100`

### مرحله 2: اتصال از موبایل
در مرورگر موبایل وارد شوید:
```
http://192.168.1.100:3000
```

### مرحله 3: Add to Home Screen (اختیاری)
**Chrome (Android):**
1. روی منو (⋮) کلیک کنید
2. **Add to Home screen** را انتخاب کنید
3. نام را تأیید کنید
4. **Add** را بزنید

**Safari (iOS):**
1. روی Share کلیک کنید
2. **Add to Home Screen** را انتخاب کنید
3. نام را تأیید کنید
4. **Add** را بزنید
