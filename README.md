## 🌟 معرفی

**ID Mobile Manager Pro** یک سیستم جامع مدیریت فروشگاه موبایل است که برای اجرا در شبکه محلی (Wi-Fi) مغازه طراحی شده است. این سیستم بدون نیاز به اینترنت کار می‌کند و از طریق شبکه داخلی قابل دسترسی است.

### 🎯 ویژگی‌های کلیدی

- ✅ **کاملاً Local** - بدون نیاز به اینترنت
- ✅ **Multi-User** - چند کاربر همزمان
- ✅ **Double-Entry Accounting** - حسابداری دوطرفه واقعی
- ✅ **RTL فارسی** - کاملاً راست‌چین با فونت وزیر
- ✅ **Responsive** - کار روی موبایل، تبلت و دسکتاپ
- ✅ **Dark Mode** - حالت تاریک
- ✅ **PWA Ready** - قابلیت نصب روی موبایل
- ✅ **Offline** - کار بدون اینترنت

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها

- **Node.js** نسخه 18 یا بالاتر
- **مرورگر مدرن** (Chrome, Firefox, Edge, Safari)
- **شبکه Wi-Fi داخلی** (برای دسترسی از موبایل)

### مراحل نصب

```bash
# 1. Clone یا دانلود پروژه
git clone <repository-url>
cd id-mobile-manager

# 2. نصب وابستگی‌ها
npm install

# 3. Build پروژه
npm run build

# 4. اجرای سرور محلی
node server.js
```

### دسترسی به برنامه

**از کامپیوتر سرور:**
```
http://localhost:3000
```

**از موبایل/تبلت در شبکه محلی:**
```
http://192.168.1.X:3000
```

### پیدا کردن IP سرور

**ویندوز:**
```cmd
ipconfig
```

**مک/لینوکس:**
```bash
ifconfig
# یا
ip addr show
```

## 💼 ماژول مالی - جزئیات کامل

### 📊 داشبورد مالی

داشبورد مالی شامل شاخص‌های زیر است:

- 💵 **موجودی نقدی** - مجموع صندوق‌ها
- 🏦 **موجودی بانک** - مجموع حساب‌های بانکی
- 💳 **کارتخوان تسویه‌نشده** - تراکنش‌های در انتظار
- 📥 **مطالبات مشتریان** - بدهی مشتریان
- 📤 **بدهی به تأمین‌کنندگان** - بدهی به فروشندگان
- 📈 **فروش/خرید/هزینه** - آمار دوره‌ای
- 💹 **سود ناخالص و خالص** - محاسبه خودکار
- 📦 **ارزش موجودی کالا** - ارزش انبار

**شاخص‌های سلامت مالی:**
- حاشیه سود ناخالص (Gross Margin)
- حاشیه سود خالص (Net Margin)
- نسبت جاری (Current Ratio)
- معادله حسابداری (Assets = Liabilities + Equity)

### 💵 صندوق و بانک

**صندوق‌ها:**
- ایجاد چند صندوق (اصلی، تعمیرات، فروش، تنخواه)
- موجودی اولیه و جاری
- تاریخچه تراکنش‌ها
- مسئول صندوق

**حساب‌های بانکی:**
- چند حساب بانکی
- شماره حساب، کارت، شبا
- موجودی اولیه و جاری

### 💸 هزینه و درآمد

**دسته‌بندی هزینه‌ها:**
- اجاره، آب، برق، گاز
- اینترنت، تلفن
- حقوق، تبلیغات
- حمل‌ونقل، تعمیرات
- کارمزد بانکی، مالیات، بیمه

**درآمدهای متفرقه:**
- خدمات، اجرت تعمیرات
- نصب گلس، نرم‌افزار
- انتقال اطلاعات

### 📈 گزارش‌های مالی

**سود و زیان (P&L):**
```
درآمدها
  - فروش کالا
  - درآمد تعمیرات
  - درآمد خدمات
  - سایر درآمدها
= جمع درآمدها

- بهای تمام‌شده کالا (COGS)
= سود ناخالص

- هزینه‌های عملیاتی
  - اجاره، حقوق، utilities
  - تبلیغات، حمل‌ونقل
  - کارمزد بانکی
= سود خالص
```

**ترازنامه (Balance Sheet):**
```
دارایی‌ها
  - صندوق‌ها
  - بانک‌ها
  - حساب‌های دریافتنی
  - موجودی کالا
  - تجهیزات

بدهی‌ها
  - حساب‌های پرداختنی
  - چک‌های پرداختنی

حقوق مالکانه
  - سرمایه
  - سود انباشته
```

**تراز آزمایشی (Trial Balance):**
- لیست تمام حساب‌ها با مانده
- بررسی تعادل بدهکار/بستانکار

**جریان نقدی (Cash Flow):**
- ورودی‌های نقدی
- خروجی‌های نقدی
- جریان نقدی خالص

### 📚 سرفصل حساب‌ها

ساختار استاندارد حسابداری:

```
1000 دارایی‌ها
  1100 صندوق‌ها
    1110 صندوق اصلی
    1120 تنخواه
  1200 بانک‌ها
  1300 حساب‌های دریافتنی
  1400 موجودی کالا
  1500 تجهیزات

  2100 حساب‌های پرداختنی
  2200 چک‌های پرداختنی

3000 حقوق مالکانه
  3100 سرمایه
  3200 سود انباشته

4000 درآمدها
  4100 فروش کالا
  4200 درآمد تعمیرات
  4300 درآمد خدمات
  4400 سایر درآمدها

5000 هزینه‌ها
  5100 بهای تمام‌شده کالا
  5200 اجاره
  5300 حقوق
  5400 آب و برق
  5500 اینترنت و تلفن
  5600 تبلیغات
  5700 حمل‌ونقل
  5800 تعمیر و نگهداری
  5900 کارمزد بانکی
  5990 سایر هزینه‌ها
```

### 📖 دفتر کل

- لیست تمام اسناد حسابداری
- فیلتر بر اساس تاریخ، حساب، شرح
- خروجی اکسل
- چاپ گزارش
- بررسی تعادل اسناد

### 📝 چک‌ها

**چک دریافتی:**
- ثبت چک از مشتری
- شماره چک، بانک، مبلغ
- تاریخ صدور و سررسید
- وضعیت (در انتظار، وصول شد، برگشتی)

**چک پرداختی:**
- ثبت چک به تأمین‌کننده
- مدیریت سررسیدها
- هشدار چک‌های نزدیک سررسید

### 🔄 انتقال بین حساب‌ها

- صندوق ↔ بانک
- بانک A ↔ بانک B
- صندوق → تنخواه
- ثبت خودکار سند حسابداری

### 👤 حساب مشتریان

- لیست مشتریان با مانده حساب
- گزارش سنی مطالبات (Aging Report):
  - جاری (0-30 روز)
  - 31-60 روز
  - 61-90 روز
  - 91-120 روز
  - بیش از 120 روز
- خروجی اکسل

### 🚚 حساب تأمین‌کنندگان

- لیست تأمین‌کنندگان با مانده حساب
- مجموع خرید، پرداخت و بدهی
- خروجی اکسل

**فرآیند فروش:**
1. اسکن بارکد یا جستجوی کالا
2. انتخاب مشتری
3. تنظیم تعداد و قیمت
4. اعمال تخفیف
5. انتخاب روش پرداخت
6. تسویه کامل یا ثبت مانده
7. ثبت و چاپ فاکتور

- ثبت کالا با تمام جزئیات

## 📊 حسابداری دوطرفه (Double-Entry)

### اصول حسابداری

تمام تراکنش‌های مالی از اصول **حسابداری دوطرفه** پیروی می‌کنند:

```
مجموع بدهکار = مجموع بستانکار
```

### اسناد خودکار

**فروش نقدی:**
```
بدهکار: صندوق/بانک
بستانکار: فروش کالا

بدهکار: بهای تمام‌شده
بستانکار: موجودی کالا
```

**فروش نسیه:**
```
بدهکار: حساب‌های دریافتنی
بستانکار: فروش کالا
```

**دریافت از مشتری:**
```
بدهکار: صندوق/بانک
بستانکار: حساب‌های دریافتنی
```

**خرید نقدی:**
```
بدهکار: موجودی کالا
بستانکار: صندوق/بانک
```

**خرید نسیه:**
```
بدهکار: موجودی کالا
```

## 📱 اتصال موبایل

### مراحل اتصال

1. **اتصال به Wi-Fi یکسان**
   - کامپیوتر سرور و موبایل باید به یک شبکه Wi-Fi متصل باشند

2. **پیدا کردن IP سرور**
   - در کامپیوتر سرور IP را پیدا کنید (مثلاً `192.168.1.100`)

3. **دسترسی از موبایل**
   ```
   http://192.168.1.100:3000
   ```

4. **Add to Home Screen (اختیاری)**
   - در Chrome: منو → Add to Home screen
   - در Safari: Share → Add to Home Screen

### ایجاد پشتیبان

3. فایل JSON را انتخاب کنید
4. تأیید کنید

## 🔧 عیب‌یابی

### منوی مالی نمایش داده نمی‌شود

**راه‌حل ۱: Refresh**
```
Ctrl + Shift + R (Hard Refresh)
```

**راه‌حل ۲: Logout و Login مجدد**
1. Logout کنید
2. دوباره با `admin` وارد شوید

**راه‌حل ۳: Clear localStorage**
```javascript
// در Console مرورگر
localStorage.clear();
location.reload();
```

### سرور اجرا نمی‌شود

**خطا: Port 3000 already in use**
```bash
# ویندوز
netstat -ano | findstr :3000
taskkill /PID <PID> /F

# یا از پورت دیگری استفاده کنید
PORT=3001 node server.js
```

### موبایل وصل نمی‌شود

- مطمئن شوید هر دو دستگاه در یک شبکه Wi-Fi هستند
- IP سرور را بررسی کنید
- فایروال را بررسی کنید

### اطلاعات ذخیره نمی‌شود

- Cache مرورگر را پاک کنید
- از مرورگر دیگری استفاده کنید
- فضای localStorage را بررسی کنید
